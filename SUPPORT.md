- [GitHub Issues](https://github.com/Tinkora/favicon_kit/issues): reproducible
  bugs and feature requests
- [GitHub Discussions](https://github.com/Tinkora/favicon_kit/discussions):
  general questions and discussion

Include the browser version, source-image dimensions, steps to reproduce, and
expected versus actual behavior. Do not use public issues for security reports.
